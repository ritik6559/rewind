# demo-repo

A tiny shopping-cart module that the Rewind agent works on during the demo. It has no dependencies. Run the tests with `npm test` (Node 26).

One test fails on purpose.

## Tasks

- **Easy:** "The tests are failing. Find the bug and fix it."
- **Stretch:** "Add a `totalCents(items, discountPercent, taxPercent)` function that applies the discount first and then the tax, with tests."

Reset after a run with `git checkout -- demo-repo && git clean -fd demo-repo`.
